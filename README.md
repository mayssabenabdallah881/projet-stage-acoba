# Stage d'été — Développement Web & Intelligence Artificielle

## Présentation

Ce dépôt présente les travaux réalisés dans le cadre de mon stage d’été chez **ACOBA**, durant lequel j’ai participé au développement d’une application web intégrant des fonctionnalités d’extraction, de traitement et d’analyse de données.

## Missions réalisées

- Développement d’une API avec **Flask** pour la recherche et l’exploitation de profils professionnels.
- Extraction de données à partir de sources web (*Web Scraping*).
- Traitement du langage naturel (NLP) avec **spaCy**.
- Classification et analyse sémantique des profils selon des critères de recherche.
- Calcul de scores de pertinence pour faciliter l’identification des profils correspondants.
- Exploitation et exportation des résultats vers des fichiers Excel avec **OpenPyXL**.

## Technologies utilisées

- **Langage :** Python
- **Backend :** Flask
- **Intelligence artificielle :** NLP, spaCy, analyse sémantique
- **Collecte de données :** Web Scraping
- **Traitement des données :** OpenPyXL, Excel

## Objectifs du stage

- Mettre en pratique mes compétences en développement Python.
- Découvrir l’intégration de techniques de NLP dans une application web.
- Automatiser certaines tâches d’extraction et d’analyse de données.
- Développer une solution facilitant la recherche de profils professionnels.
